# “铁蛋铁蛋”与关键词指令回归（2026-09-26）

当前版本只接受句首“铁蛋铁蛋”唤醒。唤醒后的最终识别文本包含“完成”“暂停”“休息”或“跳过”时，按用户确认的规则执行对应操作；命中两类以上则不执行并提示一次只说一个指令。训练状态和会话版本仍由原调度器校验。

此规则有意将“不要完成”识别为完成本组，将“延长休息”“还要休息多久”识别为跳过休息。此前把这些句子标为误操作的评测结论不再适用于当前规则；若要延长休息，仍可说不含“休息”的“延长三十秒”。

以两种系统合成声线各 28 句生成独立语音，每句测试干净、10 dB 白噪声和 8 dB 混合人声。现有 14M 端侧模型及热词分数 2.0 的逐字匹配分别为 55/56、48/56、13/56；包含重复唤醒词的 16 句在前两种条件下均为 15/16。干净条件下唯一未逐字匹配的是一个训练进度问句。合成负例中，16 句有 4 句会依新规则执行操作，主要是带唤醒词的否定句；这正是用户批准的宽松匹配行为。该合成结果不能代表真实健身房识别率。

之前提供的真人录音只说了一次“铁蛋”，因此不能用于验证重复唤醒词。原始录音、私人片段和逐句转写均未加入仓库。当前回归以单元测试及 Android 模拟器中的独立合成录音验证新唤醒方式；模型权重未更换或微调。
