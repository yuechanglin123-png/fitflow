# 第八版语音助教验证记录

日期：2026-09-24。版本号 0.8.0，versionCode 8，包名 `com.fitflow.training`。

## 变更

- 使用真实离线模型与 Android 模拟器复现动态播报时的进程闪退。崩溃记录显示 JNI 查找 Kotlin 回调的 `invoke(float[])` 方法失败，继而触发 SIGABRT。改为显式实现回调对象，并避免异常穿过原生回调边界。相同的中断、再次播报压力用例已通过。
- 调整音频播放：播放前预写入 100 毫秒静音，播报后补写 200 毫秒静音并等待播放头走完，减轻首尾截字。
- 将识别后的静音判定从库默认 1.4 秒调整为 0.65 秒；仍只根据完整结果执行训练指令。
- 固定反馈语音重新以 0.92 倍语速及完整句尾生成，动态回答使用相同语速和句尾处理。男声、女声与离线模型保持不变。
- 开启助教时仅加载固定语音索引；首次动态问答时才加载较大的语音合成模型，以降低通常训练过程中的启动延迟和内存占用。
- APK 和安装后应用静态占用验收上限改为 1,000,000,000 字节。

## 验证结果

- `:app:lintDebug :app:testDebugUnitTest :app:connectedDebugAndroidTest :app:assembleDebug`：通过；51 项单元测试、41 项 Android 模拟器测试，无失败。
- 对动态播报回归测试临时恢复旧的 Kotlin lambda 回调后，模拟器再次出现同一 `invoke(float[])` 查找失败和 JNI SIGABRT；恢复显式回调后，男声与女声完整动态播报测试通过。
- 模型和许可文件打包校验：398 项通过。
- APK：221,656,961 字节；SHA-256：`3a241550aae5ec5ca3959c573b5a03e47ab6287d5ad2fd4a1dafb1d9cb7871d5`。
