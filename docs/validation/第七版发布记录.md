## 使用

覆盖安装第七版，开始训练，打开“AI训练助教”，授权麦克风。说“小练小练”，听到回应后发出指令，也支持唤醒词和指令连说。天气先选默认城市；男女声可在助教卡中选择。允许通知后可从锁屏通知关闭助教。

语音识别与合成离线运行，天气联网。动态问答在低性能手机上可能需等待；健身房噪声、真人听感、实体ARM手机、API26、蓝牙耳机与来电场景尚未验证。首次开启会初始化模型，手机需有足够可用运行内存。

开源依赖包括eSpeak NG GPLv3；对外再分发需遵守相关源码提供要求。权重来源、许可证及可复现下载脚本已随项目保存。本次未对外发布应用。
