# 力量训练逐组卡片与动作间休息设计

## 目标

用户先批量填写一组通用参数，生成每组独立卡片，再逐组调整重量、次数和该组后的休息时间。每个动作结束后、下一个动作开始前，使用单独设置的动作间休息。保留安卓离线应用、自动结束休息、手动完成每组和手动打卡流程。

## 今日计划界面

- 动作作为纵向容器按计划顺序排列，动作容器不再固定为正方形。
- 从动作库添加动作时，继续一次填写重量、计划组数、每组次数、组间休息时间和备注。保存后按组数生成具有稳定 ID 的逐组卡片。后续可为同一动作再批量追加小组。
- 每个小组是一张方形卡片，在所属动作下从上到下排列。卡片显示第 N 组、重量、次数、完成该组后的休息时间和备注；可以单独修改重量、次数、休息时间和备注。可以删除未开始的小组。
- 每个动作提供独立的动作间休息输入，单位为秒，默认 120 秒，可在训练前修改。最后一个动作的该字段不执行。
- 重量允许 0–1000 kg，次数 1–1000，休息 0–3600 秒；沿用现有输入校验。窄屏上仍能查看和编辑每组。

## 训练规则

- 用户每按一次“完成本组”，只记录当前小组。若同一动作还有下一组，启动当前小组卡片上的休息时间；倒计时结束自动进入下一组。
- 若这是该动作最后一组且后面还有动作，只启动该动作的动作间休息，不叠加最后一组卡片上的休息时间；倒计时结束自动进入下一动作。
- 若这是整次训练的最后一组，直接进入训练总结，不执行其组间休息，也不执行动作间休息。
- 休息期间继续支持跳过和延长 30 秒。锁屏、切换应用或重开后，按保存的截止时间恢复并自动推进。完成训练仍由用户手动打卡。
- 训练中只允许修改或删除尚未完成的小组；已完成小组及其完成状态保持不变。动作排序只对尚未开始的动作开放。

## 数据与兼容

- 新计划以稳定 ID 的逐组记录保存重量、次数、组后休息和备注，并在动作上保存动作间休息。训练进度按逐组 ID 标记完成；多次批量添加产生连续小组。
- 读取旧版计划、进行中的训练和历史打卡时，将旧“多组小卡”按组数展开，保留顺序、参数和备注。旧训练已完成的组数按原顺序映射为已完成的逐组记录。旧版正在倒计时的截止时间保持不变，倒计时结束后按新计划继续。
- Room 表仍存储 JSON 文本；转换发生在读取旧数据时，并将转换后的活动计划与训练状态持久化。历史打卡保持可读，不清除用户数据。转换可重复执行而不产生重复组。

## 实现边界与验收

- 计划界面、输入表单、校验与存储、训练状态机、提醒接收器、训练总结和打卡显示同步采用逐组数据。
- 测试覆盖批量生成后逐组修改、组内休息、动作间休息覆盖最后一组休息、最后一组直接结束、旧数据转换与进度保留、后台恢复，以及完整训练流程。
