# 完整训练计划预设设计规格

## 目标

为力量训练模块增加 7 个长期保存的训练预设槽位。用户可以提前配置完整训练计划，并在需要训练相应部位时将预设快速导入今日计划，避免重复设置动作和小组参数。

## 范围

本功能包括：

- 固定 7 个训练预设槽位。
- 预设的命名、编辑、覆盖和清空。
- 从动作库或自定义动作创建预设内容。
- 将今日计划保存到指定预设槽位。
- 将预设覆盖或追加到今日计划。
- 本地 Room 数据库持久化和升级迁移。
- 完成后生成 APK，并复制到项目根目录，命名为 `第五版.apk`。

本功能仅用于力量训练模块，不扩展徒手训练或有氧模块。

## 页面入口与导航

### 动作库入口

在力量动作库页面顶部，将“训练预设”按钮放在“今日计划”旁边。点击后进入训练预设列表页。

### 训练预设列表页

列表固定显示槽位 1–7：

- 空槽位显示“尚未设置”。
- 已设置槽位显示自定义名称、动作数量和总组数。
- 点击槽位进入该槽位的编辑页。
- 已设置槽位可以清空；清空前弹出确认提示。

### 今日计划入口

今日计划页面顶部增加：

- “导入预设”：打开 7 个预设槽位供选择。
- “保存为预设”：选择目标槽位，将当前今日计划复制到该槽位。

## 预设编辑

每个预设支持：

- 自定义预设名称。
- 从力量动作库添加动作。
- 新增自定义动作。
- 调整动作顺序。
- 删除动作。
- 设置和修改动作间休息。
- 添加、修改和删除小组。
- 设置每组重量、次数、组后休息和备注。

预设编辑复用今日计划已有的紧凑小组卡片和参数编辑方式。备注最多显示两行，点击后通过方形详情框查看全文。

预设名称不能为空，并设置合理长度限制。没有有效动作、小组为空或参数校验失败的预设不能导入。

## 数据模型与存储

### 数据表

Room 数据库新增 `presets` 表：

- `slot`：整数主键，范围 1–7。
- `name`：用户自定义名称。
- `payload`：序列化后的预设内容。

数据库从当前版本升级，使用显式 Migration 创建新表，不删除或覆盖已有今日计划、训练会话和打卡记录。

### 预设模型

预设保存：

- 槽位编号。
- 名称。
- 有序动作列表。
- 每个动作的动作库 ID 或自定义名称。
- 动作间休息。
- 每个小组的重量、次数、组后休息和备注。

预设不保存训练日期。它可以复用现有计划动作和小组结构，但应使用独立的预设顶层模型。

## 保存与导入规则

### 今日计划保存为预设

- 用户选择目标槽位。
- 空槽位直接保存。
- 已有内容的槽位先确认，再整体覆盖。
- 保存时复制今日计划内容；之后修改今日计划不会影响预设，修改预设也不会影响今日计划。

### 预设导入今日计划

- 空预设不可导入。
- 导入时日期使用当前今日计划日期。
- 所有动作和小组生成新的唯一 ID，避免与预设或现有今日计划共享身份。
- 今日计划为空时直接导入。
- 今日计划非空时，每次让用户选择：
  - “覆盖今日计划”：整体替换当前动作列表。
  - “追加到末尾”：保留现有动作，将预设动作按原顺序追加。
- 追加时，即使动作名称或动作库 ID 相同，也保留为独立动作，不自动合并。

## 错误处理

- 数据库和校验错误在当前页面显示明确提示。
- 导入前再次校验预设内容。
- 保存或导入失败时保留用户现有今日计划和预设数据。
- 清空、覆盖预设和覆盖今日计划均使用确认对话框。

## 测试与验收

自动化测试至少覆盖：

1. 数据库升级后原计划、会话和打卡数据保留。
2. 固定返回 7 个预设槽位。
3. 预设新增、编辑、覆盖和清空。
4. 预设名称和计划参数校验。
5. 今日计划保存为预设。
6. 空今日计划直接导入。
7. 非空今日计划选择覆盖。
8. 非空今日计划选择追加。
9. 追加后同名动作保持独立。
10. 每次导入都为动作和小组生成新 ID。
11. 预设和今日计划修改互不影响。
12. 动作库、预设列表、预设编辑和今日计划之间的页面导航。
13. 关键用户界面的模拟器流程测试。

完成前运行 Android Lint、单元测试、全部模拟器界面测试和 APK 构建。将构建产物安装到模拟器并启动验证。最终 APK 复制到主项目根目录，文件名为 `第五版.apk`，并校验与构建产物的 SHA-256 一致。
