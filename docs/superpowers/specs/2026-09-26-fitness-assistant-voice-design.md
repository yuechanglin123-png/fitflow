# 健身助手名称与语音助教改进设计

日期：2026-09-26

## 目的与边界

用户在训练时说“铁蛋”唤醒助教，可以在助教回应“我在，请说指令”的同时说出操作指令，不丢失语音；指令识别比现版更可靠，播报略快。手机桌面与系统应用列表显示“健身助手”。保留现有应用 ID `com.fitflow.training`、已安装应用的数据、男声/女声选项、五秒无指令退出机制和离线语音能力。安装后的总大小仍低于 1 GB。

用户提供的四段真人录音位于聊天附件对应的本机 QQ 接收目录（`3.m4a`、`爸.m4a`、`妈.m4a`、`9月26日.m4a`）。录音是评测和训练候选素材，尚未核对逐句文字、说话人数量、录音环境及可用片段。原始录音和可识别个人的派生数据不得提交到公开 Git 仓库或打包进 APK。

## 方案

采用现有 sherpa-onnx Zipformer 14M 和 Kokoro TTS，先改语音流程及热词偏置，用真人录音做基线和回归评测；仅在找到兼容的训练检查点、完成逐句标注且训练集与按说话人划分的验证集足够独立时，执行监督微调并导出量化 ONNX。当前 APK 中的 int8 ONNX 文件是推理权重，不能直接当作微调检查点。“强化训练”在本项目指录音扩充、错误样本复测与监督训练迭代，不宣称进行强化学习。

不以未经验证的模型替换换取表面上更高的识别率。任何新模型都须通过真人录音与合成噪声样本的对照评测、误触发门槛、实体或模拟器运行验证及安装体积检查；否则保留原权重和已验证的适配改进。

## 应用名称和语音界面

- 修改 Android 应用标签为“健身助手”，并使语音面板的引导文案使用“铁蛋”。不改包名、数据库结构或训练数据。
- 唤醒短语必须处于识别文本开头。移除旧唤醒词“小练小练”，只接受“铁蛋”及在真人评测中确定、不会造成误唤醒的同音转写。可在一口气说“铁蛋，完成本组”。
- 热词表纳入“铁蛋”、四类训练操作及常见时间、天气问句。热词分数在带噪验证集上调节，同时检查无唤醒词、否定句和背景人声的误触发。热词偏置不称为权重微调。

## 唤醒回应期间的指令收音

- 识别到唤醒后，立即建立新的指令收音窗口，再播放缓存的“我在，请说指令”。窗口从开始回应时计五秒；用户可在回应期间或播报结束后说指令。
- 麦克风与播报同时工作时优先使用系统回声消除；识别文本若仅为助教自己的回应或其片段，不执行训练操作。用户指令形成明确的最终识别结果后，停止回应播报并进入现有严格意图解析与训练状态校验，确保一条语音最多执行一次。
- 对半句、模糊句、否定句、多操作句维持拒绝策略。五秒内没有有效完整指令则回到等待唤醒；未听清但有明显用户语音时播报现有重试提示并再给五秒。
- 关闭助教、训练完成、录音或播报失败时停止两条音频流，清理超时任务。播报与识别竞争时以最新会话代号丢弃过期回调，防止旧语音操作下一组。

## 播报速度

- 将动态 Kokoro 语速从 0.92 调至约 1.0；预缓存的男、女声短提示用同一速度重新生成，不在播放端粗暴变速。
- 保留句首静音预热和句尾缓冲。验证“我在”及短操作反馈的首尾字可听清；若少数声音在 1.0 时不自然，只调整该预录提示，不改变用户选择的声线。

## 真人录音处理和模型评测

1. 在工作区外的本机缓存解码四段录音；标记说话人、环境、逐句文字和时间边界。先与用户核对不确定的转写。仅保留完成评测所需的片段。
2. 按说话人分开训练与验证，防止同一人的相似读法同时出现在两组。先保存现版的唤醒召回、四类指令准确率、无唤醒误执行次数和端到端响应时间。
3. 用热词、同音处理和严格意图解析做轻量适配，重新评测；在兼容训练检查点和样本量满足条件后，再训练模型。训练保留基线模型与可复现参数，导出后的 int8 ONNX 在 Android 端再次评测。
4. 接受新权重的条件：真人留出集指令正确率有实测改善，误执行数不增加，唤醒延迟与内存没有明显恶化，安装总大小低于 1 GB。样本不足时明确标注结果仅适用于这批录音，不宣称健身房通用准确率提升。

## 验证

- 单元测试：新旧唤醒词、同句唤醒加指令、播报期间下达指令、播报自声过滤、五秒截止、重复回调、关闭/暂停/最后一组竞争。
- 音频评测：四段真人录音的逐句结果与旧版对照；原有合成语音、噪声和否定句语料继续用作回归，不替代真人测试。
- Android 验证：安装升级后应用名称与原有训练数据、男女声播报、麦克风回声场景、内存/崩溃日志和最终安装体积。只有在测试设备或模拟器实际运行通过后才声称设备验证完成。

## 交付与限制

交付源码、更新后的评测脚本与匿名汇总报告，以及验证通过的 Android 构建产物。原始真人录音及可还原语音的片段不进入公开仓库。若无法获取兼容训练检查点或录音不足以训练，交付热词和流程优化，并在报告中明确写出“未完成权重微调”及原因，不把热词优化称为模型训练。
