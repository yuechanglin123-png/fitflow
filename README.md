# 健身助手（Android 版）

一款离线使用的力量训练记录应用。当前版本提供力量训练动作库、今日计划、逐组完成、组间及动作间休息提醒、训练后拉伸建议和每日打卡。首页的徒手健身、有氧运动暂为后续模块。

首页“选择训练方式”旁的“新手教程”可在应用内离线翻看两页图文 PDF，并支持放大后滚动阅读。教程原件为项目根目录的 `健身助手_简明使用教程.pdf`。

## 开发环境

- Android Studio，Android SDK API 36
- JDK 17
- Android 8.0（API 26）或更新的设备

在项目根目录运行：

```powershell
.\tools\assistant\prepare-models.ps1
.\gradlew.bat :app:assembleDebug
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

源码仓库包含模型下载脚本和文件校验清单。大型模型、Android 推理库、生成的 APK、签名密钥和本机配置不纳入 Git；首次构建前请先运行上述 `prepare-models.ps1`。

首次打开后进入“力量训练”选择动作，点击动作右侧“+”一次填写重量、组数、次数、休息和备注，软件会按组数生成纵向排列的方形小组卡片。每组可单独修改重量、次数、该组后休息和备注；每个动作另有默认 120 秒、可修改的动作间休息。训练页面按动作顺序显示所有方形小组卡片，包括下一动作，当前组可直接点“完成本组”，未完成组可逐组修改。完成当前动作的最后一组后只执行动作间休息，整次训练的最后一组完成后直接进入总结。休息结束自动推进，也可跳过或延长。完成训练后可查看拉伸建议，点击“完成训练并打卡”保存当天的计划与实际完成组数。

## 日历打卡（第十版）

首页进入“每日训练打卡”后可按月份查看打卡日期，点选日期查看训练类别、动作与每组小卡内容，以及完成组数和计划组数。打卡类别包括力量训练、徒手训练、有氧运动。训练总结自动登记力量训练及实际进度；过去未打卡的日期可以补卡，逐个添加动作和小卡，并填写每个动作完成到第几组。若该日已有保存的计划，补卡时会先载入，仍可修改和增补。未来日期不能补卡。旧版打卡如果没有保存具体完成组数，会显示“完成度未记录”。

## 完整训练预设

力量动作库顶部的“训练预设”提供 7 个长期保存的槽位。每个槽位可以自定义名称，并单独编辑动作顺序、每组重量和次数、组后休息、动作间休息及备注。预设既支持从动作库添加动作，也支持自定义动作；尚未配置小组的草稿可以继续保存和编辑，但不能导入今日计划。

今日计划顶部可以“保存为预设”或“导入预设”。保存到已有槽位时会先确认整体覆盖。今日计划已有内容时，每次导入都可选择“覆盖今日计划”或“追加到末尾”；追加时，同名动作仍作为两个独立动作保留。预设与今日计划之间使用独立副本，后续修改互不影响。

训练计划、7 个训练预设、进行中的训练和打卡历史保存在手机本地 Room 数据库中。卸载或清除应用数据会删除记录，没有账号与云端同步。

## AI 训练助教（第十四版）

训练界面打开“AI 训练助教”并允许麦克风后，先说“你好教练”，也可以连着说“你好教练，完成本组”。新版识别到完整唤醒词的流式结果就回应，无需等待整句话结束；可以在“我在，请说指令”播报期间说出指令。

开启期间麦克风持续采集，等待唤醒、听指令、回复之间复用同一个录音会话。普通回复和提醒期间暂不识别，持续读出并丢弃音频，避免把助教自己的播报当成指令；播报结束后重新识别。关闭助教、结束训练或丢失音频焦点时停止采集。进程重启不会自动开启录音。

唤醒后 5 秒内没有指令会返回等待唤醒。听到了未完成或无法识别的内容时，会提示“对不起，我没有听清，请再说一次”，播完后重新等待 5 秒。每次唤醒执行一项操作：

- 包含“完成”：完成本组。
- 包含“休息”或“跳过”：跳过休息。
- 包含“暂停”：暂停训练；恢复训练仍点击继续按钮。
- 同一句命中多个操作类别：不执行，提示一次只说一个指令。
- 延长休息请说“延长三十秒”或“加三十秒”。按已确认的字面匹配规则，“延长休息”和“还要休息多久”会执行跳过休息。

可以询问时间、日期、当前动作、剩余组数和天气；天气需先设置默认城市，也可以说“北京今天天气”。男声、女声可以随时切换；通知中也可关闭助教。休息剩余 10 秒提醒准备，未暂停训练每满 10 分钟鼓励一次。

识别与播报在本机运行，不上传录音。沿用 14M 中文识别模型和两条推理线程；录音读取粒度从 100 毫秒降为 50 毫秒，语音结束静音阈值从 650 毫秒降为 450 毫秒。它们是处理参数，不代表所有手机上的实际响应时间。动态语音模型按需加载，固定提醒和反馈使用本地缓存。

第十五版在开启助教时将常用操作反馈载入内存，并在多次播报间复用 Android 音频通道。缓存反馈的前置保护静音由 100 毫秒缩短到 10 毫秒，识别并执行指令后立即开始对应播报；仍保留尾部缓冲，避免最后一个字被截断。模拟器上的缓存播报额外总时长从约 336 毫秒降到约 200 毫秒，其中约 200 毫秒为播报结束后的尾部保护，不影响首字开始时间。

训练界面在暂停按钮旁提供“结束训练”。点击后保留已经完成的组数，停止当前休息和 AI 助教，并直接进入训练总结；未完成的小组继续按未完成记录。

支持 Android 8.0 以上的 arm64-v8a 手机和 x86_64 模拟器。APK 小于 1 GB，使用原调试签名，可直接覆盖安装保留训练记录。实体健身房噪声、蓝牙耳机和不同手机的回声抑制仍需实测。评测结果见 [持续收音与唤醒优化](docs/validation/fitness-assistant-continuous-wake.md)。第三方模型及运行库许可见 `app/src/main/assets/assistant/licenses/`。

## 提醒与动作资料

Android 13 及以上需要用户主动允许通知。Android 12 及以上如果没有开启“闹钟和提醒”特殊权限，系统提醒使用非精确闹钟，可能延迟。应用内倒计时按保存的截止时间计算；回到应用后可继续确认下一组。不同厂商的省电策略可能进一步影响后台提醒。

动作库的中文注意事项由本项目重新撰写，资料链接指向 NASM 公开动作页面。拉伸说明参考 ACE 和 NHS 公开页面；拉伸卡的视频链接指向含相应动作演示的 NHS 页面；部分页面收录多个动作，进入后请按动作名称选择对应片段。图解为项目原创简图。若动作引起疼痛或不适，应停止。

动作资料：

- [NASM 动作库](https://www.nasm.org/resource-center/exercise-library)
- [ACE 动作库](https://www.acefitness.org/resources/everyone/exercise-library/)
- [NHS 训练后拉伸](https://www.nhs.uk/live-well/exercise/how-to-stretch-after-exercising/)

## 验证

```powershell
.\gradlew.bat :app:lintDebug :app:testDebugUnitTest :app:connectedDebugAndroidTest :app:assembleDebug
```

UI 测试使用 API 36 模拟器。调试 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。

本机原项目位于中文目录时，Java 17 的测试参数文件编码需要匹配 Windows 的 GBK。若所有测试均出现 `ClassNotFoundException`，使用以下已验证命令；英文工作目录可使用前述普通命令：

```powershell
.\gradlew.bat :app:testDebugUnitTest '-Dorg.gradle.jvmargs=-Xmx3g -Dfile.encoding=GBK'
```

本机 Android Studio 自带 JBR 25 与当前 Gradle 8.13 不兼容，构建请继续使用已安装的 JDK 17。
